使用文档

🎮 什么是「资产库」？

《爷爷的地》支持玩家自定义世界内容。一个「资产库」就是一个 .json 文件，里面装着一批名字、支线、事件或节日。把文件放进指定文件夹后，开局创建世界时就能选择使用它——你的世界从此与众不同。

🚀 快速开始（3 步）

  1. 打开 AI 工坊，填入你的 AI API Key，描述想要的内容，点击生成
  2. 下载生成的 .json 文件
  3. 把文件放进对应文件夹（见下方路径），重启游戏，在开局「世界内容」页选择你的库

📁 资产文件放哪里？

Windows 下，游戏存档目录（persistentDataPath）为：

C:\Users\你的用户名\AppData\LocalLow\<公司名>\<游戏名>\NameLibraries\

在该目录下按类型分文件夹存放：

NameLibraries\
  ├─ CityNames\      城市名库\我的城市名.json
  ├─ NPCNames\       NPC名字库\江南人名.json
  ├─ CompanyNames\   公司名库\
  ├─ FamilyNames\    家族名库\
  ├─ SpecialNPCs\    特定NPC库\
  ├─ Quests\         支线库\温泉镇支线.json
  ├─ Events\         事件库\
  └─ Festivals\      节日库\
💡 快速打开存档目录：按 Win + R，输入 %userprofile%\AppData\LocalLow 回车，再进入对应的公司/游戏文件夹。

📄 资产格式说明

名字型（城市名 / NPC名 / 公司名 / 家族名）——简单直接：

{
  "Items": [ "青石镇", "落霞村", "烟雨渡" ]
}

内容型（支线 / 事件 / 节日 / 特定NPC）——字段更丰富：

{
  "Entries": [
    {
      "Name": "温泉修复计划",
      "Description": "旅店老板娘的温泉设施年久失修……",
      "Stages": [
        { "StageName": "勘察温泉", "Description": "前往后山查看温泉源头" },
        { "StageName": "筹集材料", "Description": "收集 10 块石料与 5 根木材" }
      ],
      "Weight": 10,
      "CooldownDays": 0,
      "LinkedEventIds": []
    }
  ]
}

字段说明

字段说明
Name条目名称
Description详细描述，会展示给玩家
Stages阶段列表（支线流程），每项含 StageName 与 Description
Weight随机权重，越大越常出现（默认 10）
CooldownDays触发后的冷却天数（事件/节日用）
RuleType节日规则：Periodic 周期性 / BySeason 按季节 / ByDayInYear 按每年第几天
RuleSeasonSpring / Summer / Autumn / Winter（BySeason 用）
RulePeriodDays周期天数（Periodic 用，默认 15）
RuleDurationDays节日持续天数（默认 1）
LinkedEventIds关联的事件 Id 列表（节日联动用）

❓ 常见问题

  • 放进去后游戏里看不到？ 确认文件后缀是 .json 而不是 .txt；确认放在正确的类型子文件夹；重启游戏。
  • JSON 报错？ 常见原因：中文引号（""）代替了英文引号（"）、末尾多了逗号。用 AI 工坊生成的文件不会有这个问题。
  • API Key 安全吗？ 工坊页面里你的 Key 只存在你的浏览器本地，调用从你的浏览器直达 AI 服务商，不经过本站任何服务器。
  • 生成时要花钱吗？ 使用你自己的 API Key，费用由 AI 服务商按用量向你收取（DeepSeek 生成一个库通常只需几厘钱）。
